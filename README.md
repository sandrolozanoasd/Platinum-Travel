# Platinium Travel - Sitio web

Propuesta de sitio web responsive para Platinium Travel, adaptada a partir de una estructura previa HTML/CSS/JavaScript.

## Archivos
- `index.html`: contenido principal
- `style.css`: diseño responsive
- `script.js`: menú, animaciones, botón superior y cotización por WhatsApp



> Los destinos mostrados son propuestas visuales/referenciales y no incluyen tarifas ni disponibilidad garantizada.
